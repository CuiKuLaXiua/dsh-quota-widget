## 1. 总览

### 方案 A｜仪表盘（KPI 头 + 构成带 + 等分次级）★推荐

```
┌────────────────────────────────────────────────────────────┐
│ 总览                                       近 30 天 · 6 天有数据 │
│                                                            │
│  739.5M           ▁▂▅▇▆▄▃▂  ← 7 日迷你趋势        ╭───╮      │
│  总量            日均 123.2M  ↑12.4%             │96 │ 命中率 │
│                                                 ╰───╯      │
│  ████████████████████████████████████████████████▏▏▕▏      │
│  新输入 3.6%        缓存读 96.3%          输出 0.4%         │
│  ─────────┬────────────┬────────────┬────────────          │
│   3241    │    173     │    3256    │    4182              │
│   回复     │    轮次     │    步数     │   工具调用           │
└────────────────────────────────────────────────────────────┘
```
- **主数字 28px**（总量）+ 日均/环比 10px 副行；右侧 44px SVG 环形命中率（进度弧 + 中心数字）
- 构成带高 12px、圆角 6px、三段**两端各留 2px**；段内 ≥12% 才写字（白字 9px/700）
- 段下方一行**端点标签**（左/中/右对齐），颜色与段同色，10px
- 底部 4 个次级指标：**等分 4 列**、列间 1px 竖线、数字 14px/700 + 标签 10px
- 环比胶囊：`↑12.4%` 绿/红底 12% 透明、圆角 999；覆盖不足时显示灰字「上期覆盖 3/30 天」
- 成本：**M**（重排 + 环形 SVG + 迷你趋势）
- 优：层次最强，一眼看到"总量/命中率/日均"三个结论；缺：高度从 ~70px 增至 ~110px

### 方案 B｜三色卡（新输入 / 缓存读 / 输出）

```
┌──────────────┐┌──────────────┐┌──────────────┐
│ 新输入        ││ 缓存读        ││ 输出          │
│ 27.6M  ↑199% ││ 725.5M  ─    ││ 3.05M  ↑11%  │
│ ▁▂▃▅▆▇        ││ ▇▇▆▇▇█      ││ ▁▁▂▁▂▃      │
│ 占 3.6%       ││ 占 96.3%     ││ 占 0.4%      │
└──────────────┘└──────────────┘└──────────────┘
  回复 3241 · 轮次 173 · 步数 3256 · 工具 4182
```
- 三张等宽小卡，各自 20px 大数字 + 7 日 sparkline + 占比
- 优：三段口径最清楚，"缓存读占 96%" 的冲击力最强；缺：总量被弱化，三卡结构重复

### 方案 C｜一行摘要（最省空间）

```
739.5M 总量 · 96.3% 命中 · 日均 123.2M · ↑12.4%      [详情 ▾]
```
- 折叠态一行；展开后回到 9 个 chip
- 优：极省高度，适合一屏塞更多卡；缺：默认看不到细项

## 2. 图表（柱 / 折线 / 热力 / 时段）

### 2.1 柱状图 / 折线

#### 方案 A｜坐标系图表（y 轴刻度 + 网格 + 选中聚焦）★推荐

```
 739M ┤─────────────────────────────────────────────
      │        ▁▂▅▇▆▄▃▂        ← 折线模式
 370M ┤─────────────────────────────────────────────
      │  ▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌   ← 柱状模式
   0  ┤─────────────────────────────────────────────
      09-18      09-25       10-02       10-09    10-16
                          峰值 48.2M · 10-12
```
- 左轴 3 档（0 / ½ / 峰值），**刻度值 9px 灰色**；横向虚线 1px rgba(255,255,255,.08)
- 底部 x 轴只标首/中/末（30 天）或全部（7 天），9px
- 点击某根柱 → 该日**描边高亮**、其余柱透明度 .35（focus + context）；再点取消
- hover：柱顶浮出数值气泡（跟随光标，替代原生 title）
- 优：量级终于可比；缺：实现量 M+，30 天柱子会变细（柱宽自适应 min 3px）

#### 方案 B｜面积 + 柱混合（趋势优先）

- 折线/面积作主形态，柱只在 7d 视图作为背景；命中率用右侧轴（已有）
- 优：趋势最直观；缺：单日对比弱

#### 方案 C｜极简卡片图（无轴，仅 hover）

- 现状 + 顶部一行「峰值日 / 日均 / 环比」三个小标签
- 优：干净；缺：量级仍不可比

## 6. 三套组合（直接整套选）

| 组合 | 总览 | 图表 | 排行 | 实时 | 最近调用 | 气质 | 成本 |
|---|---|---|---|---|---|---|---|
| ① 专业监控 | A 仪表盘 | A 坐标系 | B 表格 | B sparkline | B 表格 | 像 APM 面板，信息密度最高 | **L** |
| ② 轻卡片（**推荐**） | A 仪表盘 | A 坐标系 | C 精修列表 | B sparkline | A 时间线 | 现代、有重点，不过度报表化 | **M** |
| ③ 极简一行 | C 一行摘要 | C 极简图 | C 精修列表 | C 状态条 | B 表格 | 一屏塞下所有卡，最省高度 | **S** |

> 成本：S ≈ 半天（只改样式/结构），M ≈ 1 天（+SVG/sparkline/下钻），L ≈ 2 天（+坐标轴/表格/浮层）。

## 7. 落地建议

1. 先做**总览（方案 A）**一个模块给你看效果——它最能体现"层次"是否合你口味，改动独立、可随时回退。
2. 满意后再做**图表 A**（y 轴 + 点击聚焦）与**排行 C**（两行制 + 序号）。
3. 最后做**实时 B**（sparkline）与**最近调用 A**（时间线）。
