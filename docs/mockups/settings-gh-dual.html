  • 品牌色自动换向：珊瑚用 color-mix 与 label-primary 混合。 浅色下 label 深 → 珊瑚压深；深色下 label 浅 → 珊瑚提亮。一个表达式两种结果
  • 插件侧零浅色代码：没有任何 @media (prefers-color-scheme) 的组件覆盖， 唯一的媒体查询用来给"模拟宿主"赋不同值
  • 关键决定：hero 带在两种极性下都保持深色 —— 它是结构重音，不随主题翻转
