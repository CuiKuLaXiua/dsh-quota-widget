做法：名称与数值之间插一列 118px 的横条（14px 高，带淡底槽）。
强项：分布的"断崖"最直观，横条本身就是柱状图；适合快速扫。
代价：占掉 118px 宽度，名称列被压缩（长模型名会更早出现省略号）；视觉上比 B 重。

我的建议：B。这个表格最常被问的问题是"谁占大头、断崖在哪"， B 的细条把数量级画了出来，而数字仍是主角；46px 的条不会喧宾夺主。
A 太素、C 丢了纵向对齐（且序号对按日/按小时无意义）、D 占宽 118px 会压缩模型名。

一个必须说明的取舍：占比条用线性比例，所以 1.2% 只剩 0.6px 几乎看不见。 我没有用平方根或对数"放大"长尾 —— 那会让 72.3% 与 1.2% 的 66 倍差距看起来只有 5 倍， 在表格里歪曲比例就是误导。长尾的数字本身仍然可读（1.2% / 1.1%），只是条形不承诺可见。
