五个方案的差异（都是「环 + 环内百分比」）
  • 方案 1 极细环 + 内衬底：环 2px、直径 38px；数字背后有一层淡圆衬底，把数字和环"分层"，最清晰。数字 13px。
  • 方案 2 粗环 + 内凹槽：环 4.6px、端点是方切口（不用圆头，更机械）；内圈是压暗的凹槽，数字 11.5px 带投影。立体感最强。
  • 方案 3 渐变环 + 渐变数字：环 3.6px 圆头 + 外发光；数字也用渐变（background-clip:text），环与数字同色系呼应，最"科技"。
  • 方案 4 开口仪表 + 大数字：环开口 50°（正下方），可见弧 310°；进度终点有圆点标记；因为开口让出了视觉重心，数字可以放大到 14.5px。仪表感最强。
  • 方案 5 双色反衬环：底圈把"未命中部分"画成淡粉色而不是留空，于是 99% 时那 1% 是肉眼可见的浅粉段。语义最直白：一眼看出"差一点点"。

技术差异：1 用了内衬底圆；2 用径向压暗做凹槽 + 方端点；3 用 background-clip:text 做渐变数字；4 用大开口 + 末端 marker；5 用"底圈实色"替代"轨道留空"。
