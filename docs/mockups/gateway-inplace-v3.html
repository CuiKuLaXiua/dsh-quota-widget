我推荐 A：在"必须垂直关联"这个前提下，竖线是唯一能一眼看出"上下是一组"的手段，而且它同时让两数可相减（102.7 − 100.4 = 2.3M 本机量）。
B 适合你还想要胶囊质感、且希望网关看起来"可点开"；C 适合你厌恶任何新增线条。
