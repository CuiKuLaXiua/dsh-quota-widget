悬浮面板 · 材质样板

主题
背景

第 1 张是插件当前默认的「经典背板」（= 材质层引入前的原样），其余为可选材质； 带「已落地」标记的三款（液态玻璃 / 亚克力 / 哑光纸）已可在「设置 → 用量与额度 → 通用 → 面板材质」切换。 全部 纯 CSS（零图片、零依赖），面板尺寸与插件一致 260px。 右上角切换背景 / 明暗，重点看：文字是否仍然清晰、边框是否"发脏"、模糊后底层内容是否还能透出层次。

当前落点

默认 经典背板（老用户升级后观感不变）；可选 液态玻璃 / 亚克力 / 哑光纸，在设置里手动切换，只存本机 localStorage。其余 6 款为设计备选，未接入插件。

落地注意

面板是 position:fixed 悬浮层，backdrop-filter 会按帧重算模糊。低端机可降级为不透明渐变；overflow:hidden 已加，避免模糊边缘溢出圆角。

主题变量

材质层只改背景 / 边框 / 阴影，文字与进度条颜色全部走 --dsw-alias-*，明暗主题各自一套，不改插件原有语义色。
