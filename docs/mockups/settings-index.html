设置页七 Tab · 十款模版 + 一款双极性打磨版

仅模版 · 未改源码

十款基础模版全部基于 awesome-design-md 的真实品牌设计系统，统一套用当前插件的七个 Tab： 用量统计、用量查询、外观、数据源、通用、维护、网关。 每份的 Tab 都能点、pill 与开关都能切。第二轮换了选型方向：第一轮是「四暗一亮 + 开发者工具」， 第二轮补上「三亮两暗 + 金融 / 编辑 / 内容平台」。

最上面那张是打磨版：取 G 的暖色气质 + H 的 hero/图标网格布局， 并把「深浅主题适配」真正做完。用的是三层架构—— 结构色全部继承 DSH 的 --dsw-alias-*（和悬浮面板 .oq-card 同一机制， 换主题时宿主重算变量值，插件不用改一行）；品牌珊瑚色用 color-mix 与 label-primary 混合，浅色下自动压深、深色下自动提亮，一个表达式两种结果。 支持「跟随系统 / 宿主浅色 / 宿主深色 / 并排对照」四种查看方式， 两套极性共 18 项对比度全部达到 WCAG AA。

改动只落在 docs/mockups/，lib/ 下一个字节都没动。

勾掉不接受的

选定后告诉我字母即可（例如「G」或「G + J 混」）。我也可以做混合方案： 例如「J 的暗顶亮底 + G 的衬线标题 + I 的等宽技术标签」，这类跨轮组合通常比单款更接近「既专业又不冷」。

◆ 第二轮我的判断：若第一轮都不满意，最可能是「深色开发者工具」这条路本身不对——那说明你要的是暖一点、有编辑气质的设置页。 按这个假设，G Claude 是最值得看的一款：它是十款里唯一靠衬线 + 暖色建立气质的，读者感最强，且左目录结构正好解决七项折行。 如果只是嫌第一轮太冷但不想变浅，J Supabase 更稳：暗顶亮底兼顾「专业」与「不压抑」。 要「一眼抓人」选 H Notion，代价是粉彩在暗色宿主里最容易显花。
